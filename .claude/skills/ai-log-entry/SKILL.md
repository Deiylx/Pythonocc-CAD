# Строка журнала AI_LOG

Аргументы: $ARGUMENTS

Журналы ведут люди (`AGENTS.md`): ИИ готовит черновик, человек подтверждает.

## Формат

Таблица в `logs/AI_LOG_<имя>.md`, колонки ровно такие (как в шапке файла):

`дата | итерация | кто и чем | цель | ключевой промпт | где ИИ ошибся | как исправили | результат`

## Как заполнять

Механические колонки — заполняй сам, без пометки:

- **дата** — сегодняшняя, формат `ДД.ММ.ГГГГ` (как в существующих строках).
- **итерация** — номер из аргументов; если не дан — наибольший номер в таблице + 1, и в показе
  отметь «(номер авто, поправь, если это та же итерация)».
- **кто и чем** — человек по журналу (`sergey` → Сергей, `dmitry` → Дмитрий; имя не ясно — спроси)
  и инструмент с моделью: например «Сергей; Claude Code (Opus 5.5)». Модель бери из своей
  системной информации; если в итерации был Gemini — модель из последних строк
  `logs/gemini_calls.jsonl`. Субагентов (coder, reviewer) перечисли, если они работали.
- **цель** — цель итерации одной фразой (из аргументов или из плана итерации).

Остальное:

- **ключевой промпт** — короткая цитата главной просьбы человека (≤ 1 фразы), с пометкой «черновик ИИ».
- **где ИИ ошибся**, **как исправили** — всегда начинаются с «черновик ИИ:». Пиши конкретно: что ИИ
  сделал не так (выдуманная функция, не тот Python, не та ветка, лишние правки…), кто заметил
  (человек, reviewer, тест, ruff, Gemini). Если ты не видишь у себя ошибок — так и напиши:
  «черновик ИИ: ИИ ошибок не отметил — проверить человеку». **«Ошибок не было» не пиши никогда**:
  это решает только человек.
- **результат** — только факты, которые ты видел: например «тесты OK (Ran 37)», «ruff: All checks passed!»,
  «ревью: 2 замечания, исправлены». Не видел вывод — не пиши результат, поставь «—».

В ячейках не должно быть символа `|` (замени на «/») и переводов строк.

## Шаги

1. Прочитай нужный `logs/AI_LOG_<имя>.md`: шапку и последние строки (номер итерации, стиль).
2. Собери строку по правилам выше и **покажи её человеку** целиком, в блоке кода.
3. Жди «ок» (или правок). Без «ок» файл не трогай.
4. После «ок» допиши строку в конец таблицы инструментом Edit (UTF-8, не через терминал),
   затем покажи `git diff logs/` — видно, что добавлена ровно одна строка.
