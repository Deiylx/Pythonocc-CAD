# Итерация

Цель: $ARGUMENTS

Если цель не указана — спроси её одной фразой и остановись.

## Шаги

1. **Перечитай правила.** Открой `AGENTS.md`. Особенно: куда можно писать, Python 3.7, pythonocc 7.4, `Assemble.py` (GBK) не трогать.
2. **План словами.** 1–3 шага, какие файлы изменятся, примерно сколько строк (итерация ≤ ~150 строк). Если цель больше — предложи разбить.
3. **Жди «ок».** Ничего не меняй, пока человек не ответит «ок» (или не поправит план).
4. **Один шаг.** Пиши код только в `cad_io/` и `tests/` (можно поручить субагенту `coder`). Каждую функцию OCC сначала найди в `Win64/python3.7/Lib/site-packages/OCC/Core/<Модуль>.py`. Не нашёл — не используй и скажи об этом.
5. **Тесты** — встроенным Python, из корня проекта:

   ```
   .\Win64\python3.7\python.exe -B -m unittest discover -s tests -v
   ```

   Покажи последние строки вывода как есть (`OK` или `FAILED` с причиной). Не пересказывай «всё прошло», если не видел `OK`.
6. **Ревью.** Обычный `git diff` не показывает новые (неотслеживаемые) файлы, поэтому:

   ```
   git status --short
   git add -N cad_io tests
   git diff
   ```

   `git add -N` только помечает новые файлы «будут добавлены», ничего не коммитит; после ревью можно вернуть как было: `git reset -- cad_io tests`.
   Передай субагенту `reviewer` **оба** вывода: `git status --short` (видны все изменённые и новые файлы, в том числе вне `cad_io/` и `tests/` — их diff не покажет) и `git diff`. Покажи его замечания и что из них исправлено.
7. **Черновик строки журнала** для `logs/AI_LOG_<имя>.md` (имя спроси, если неясно) в формате таблицы журнала:
   `дата | итерация | кто и чем | цель | ключевой промпт | где ИИ ошибся | как исправили | результат`.
   Колонки «где ИИ ошибся» и «как исправили» помечай «черновик ИИ». «Ошибок не было» не пиши — это решает только человек. Покажи строку и допиши в файл только после подтверждения.
8. **Коммит и пуш не делай**, если человек явно не попросил. Ветка по умолчанию — `master`.

## Итог для человека

Коротко: что сделано, результат тестов, замечания ревью, ссылка на черновик строки журнала, что предлагается следующим шагом.
